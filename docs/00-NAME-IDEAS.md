# Extension Name

## ✅ Chosen: LeetSync

**Why it works:**
- "Leet" — instantly signals LeetCode to any developer
- "Sync" — exactly describes what it does (syncs solutions to GitHub)
- Clean, two-syllable, easy to remember
- Works as a Chrome Web Store listing name
- Works as a GitHub repo name: `leetsync`
- Works as a brand: LeetSync™

---

## Internal Project Details

| Field | Value |
|-------|-------|
| Extension name | LeetSync |
| Repo folder name | `leetsync` (when renamed) |

| Tagline | *Sync your LeetCode solutions to GitHub, automatically.* |
| Badge text on success | `✓` (green) |
